# Grok Prompts

This section contains prompts optimized for xAI's Grok models (Grok-1, Grok-1.5, etc.).

## Usage
Grok is known for its "spicy" mode and real-time access to X (Twitter) data.
- **Trend Analysis:** Use the "Data Interpretation Mentor" to analyze current events.
- **Uncensored/Bold:** Some prompts can be adapted for more direct or humorous outputs if Grok's specific mode is enabled.

## Tips
Paste the system instruction directly into the chat. Grok handles long context well.
