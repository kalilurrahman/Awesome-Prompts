# Other Prompts (Mistral, Gwen, CoPilot, Llama, etc.)

This folder serves as a repository for prompts tested on open-weights models and other commercial assistants.

## Supported Models
- **Mistral / Mixtral:** Great for reasoning and coding.
- **Llama 3:** Excellent general-purpose performance.
- **GitHub CoPilot:** Use "Technical Documentation Architect" for code comments.
- **Qwen:** Strong performance in multi-lingual contexts.

## Usage
Most of these models follow standard "System Prompt" formats. You can usually paste the prompt at the beginning of the conversation or in the dedicated "System Prompt" field if using a UI like LM Studio, Ollama, or OpenWebUI.
