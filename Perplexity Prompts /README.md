# Perplexity Prompts

Prompts designed to leverage Perplexity's search-grounded capabilities.

## Usage
Perplexity is a "Answer Engine". To use these personas effectively:
1. **Focus:** Set the focus to "Writing" or "All" depending on the need.
2. **Instruction:** Paste the system prompt.
3. **Query:** Follow up with your specific research question (e.g., "Find the latest papers on...").

The "Research & Analysis" category from the main collection is particularly powerful here.
