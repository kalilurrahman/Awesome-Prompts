# Claude Prompts

This folder is the home of the extended **Educational Prompts Collection**.

## 📂 Key Files
* **`claude_educational_prompts_1-500.html`**: A massive collection of **500 system prompts** (Version 3.0). This includes the original 100 plus 400 additional generated variations covering a broader range of topics like Health, Technology, and Lifestyle.

## Usage
1. Download `claude_educational_prompts_1-500.html`.
2. Open it in your browser.
3. Search for a persona (e.g., "Socratic Dialogue Facilitator").
4. Copy the prompt and paste it into a Project or Artifact in Claude.ai.

## Why Claude?
These prompts are particularly effective with Claude's large context window and ability to follow complex system instructions without deviation.
