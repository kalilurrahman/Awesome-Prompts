# ChatGPT Prompts

This folder contains prompts specifically optimized or tested for OpenAI's ChatGPT models (GPT-3.5, GPT-4, GPT-4o, etc.).

## Usage
While the core collection in the root directory (`Claude_100_Prompts.html`) is model-agnostic, the prompts here are tuned to leverage specific features of ChatGPT, such as:
- **Reasoning Models (o1):** Prompts that encourage step-by-step thinking.
- **Custom Instructions:** Guidelines on how to add these to your User Profile.

## Quick Start
1. Browse the prompts in the root directory.
2. Copy the "System Instruction".
3. Paste it into a new ChatGPT chat or your Custom Instructions.
