# Gemini Prompts

This directory focuses on prompts tailored for Google's Gemini models (Pro, Ultra, Flash).

## Usage
Gemini excels at multimodal tasks and real-time information. The prompts in this collection can be used to:
- **Analyze Data:** Use the "Data Interpretation Mentor" prompt with uploaded spreadsheets.
- **Creative Writing:** Use the "Storytelling Architect" prompt for long-form content.

## Quick Tip
When using these prompts in Gemini, you can start your session with:
> "Act as the persona defined below. [Paste Prompt]"

*Specific Gemini-optimized prompt variations will be curated here.*
